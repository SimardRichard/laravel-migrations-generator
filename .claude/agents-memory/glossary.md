# Glossaire

## GSTI
Groupe Solutions TI.

## Module
Unité fonctionnelle autonome sous `app/Modules/{Name}/`.

## Reference Model
Table BD pour valeurs énumérées admin-éditables (ex: InvoiceStatus). Remplace les Enums PHP.

## Module Config
Model BD pour configuration métier d'un module (ex: FacturationConfig). Remplace config/*.php pour les valeurs métier.

## MCP
Model Context Protocol — exposer outils/ressources aux LLM via `laravel/mcp`.
